# Security policy

## Supported versions

Security fixes are applied to the latest release and `main`.

## Reporting

Please use GitHub private vulnerability reporting when available. Do not open a public issue containing credentials, personal network identifiers, or an exploitable endpoint detail.

## Safety boundary

CEXLENS uses public endpoints only. API keys, private account access, live orders, certificate-validation bypasses, and destructive network behavior are outside the project boundary. A proposal that changes this boundary requires a separate threat model and explicit maintainer approval.
